## 🛠️ Tech Stack & Architecture
* **Markup & Structure:** Semantic HTML5
* **Styling:** Custom CSS3 with CSS Custom Properties (Variables) supporting dynamic **Light / Dark Mode** persistence.
* **Interactivity:** Vanilla JavaScript (ES6+) powering clipboard API copy-to-clipboard actions, toast notifications, and theme toggling.
* **Typography:** Inter (Primary sans-serif) & JetBrains Mono (Code/Metadata monospace).
* **Hosting:** GitHub Pages (Static site deployment).
